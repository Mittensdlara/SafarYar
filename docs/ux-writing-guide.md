# راهنمای UX Writing سفر یار

## لحن کلی
- دوستانه، الهام‌بخش و محاوره‌ای.
- استفاده از ضمایر دوم شخص مفرد برای ایجاد صمیمیت.
- تاکید بر امکانات و حس کشف.
- رعایت رسم‌الخط فارسی (نیم‌فاصله، اعداد فارسی در متن).

## اصول کلیدی
1. **شفافیت:** پیام‌ها کوتاه، با فعل‌های کنش‌محور.
2. **تشویق:** پس از هر گام سخت، پیام مثبت نمایش داده شود.
3. **شخصی‌سازی:** استفاده از نام کاربر در صورت امکان.
4. **راهنمایی:** در فرم‌ها، راهنمای مختصر قبل از فیلد.

## نمونه پیام‌ها بر اساس سناریو
| سناریو | متن پیشنهادی |
| --- | --- |
| صفحه ورود | `سلام! شماره‌تو بزن تا سفر بعدی رو با هم بچینیم.` |
| تایید OTP | `کد ۴ رقمی رو فرستادیم. اگه نرسید، بعد از ۳۰ ثانیه دوباره ارسال می‌کنیم.` |
| پرسشنامه علایق | `کجا بیشتر حالتو خوب می‌کنه؟ جنگل‌های شمال یا کویرهای رازآلود؟` |
| پیشنهاد مقصد | `هوای شیراز عالیه؛ وقتشه بری حافظیه!` |
| بودجه‌بندی | `فقط بودجه‌تو بگو، برنامه‌ی خاص خودتو می‌چینیم.` |
| پیشرفت سفر | `👏 عالیه! تا الان ۲۰٪ از دیدنی‌های اصفهان رو دیدی!` |
| کیف پول گروهی | `هزینه‌ها رو شفاف تقسیم کنیم تا همه با خیال راحت سفر کنن.` |
| Voice Assistant | `سلام! بگو امروز دنبال چه تجربه‌ای هستی؟` |
| خطا (اینترنت) | `اتصال قطع شد، ولی نگران نباش؛ برنامه‌ت رو آفلاین نگه داشتیم.` |

## میکروکپی فرم‌ها
- **ورود شماره:** `شماره موبایل ۱۱ رقمی‌ت رو وارد کن`
- **رمز عبور:** `برای امنیت بیشتر از اعداد و حروف استفاده کن`
- **بودجه:** `سقف هزینه سفر رو به تومان بنویس`
- **اعلان موقعیت:** `با روشن کردن موقعیت، مکان‌های اطراف رو لحظه‌ای می‌بینی`

## پیام‌های آموزشی (Tooltips)
- `با کشیدن کارت‌ها، پیشنهادهای بیشتری ببین`
- `میشه به برنامه سفر فعالیت‌های دلخواهت رو اضافه کنی`
- `هر وقت خواستی هزینه جدیدی رو در کیف پول ثبت کن`

## راهنمای برندینگ واژگان
- استفاده از واژه‌ی «سفر یار» برای اشاره به اپلیکیشن.
- واژه‌ی «دونگ» برای تقسیم هزینه بین اعضای گروه.
- «نشان» به جای Badge.
- «برنامه سفر» به جای Itinerary.

## دستیار صوتی
- پاسخ‌ها باید کوتاه (< ۳ جمله) و شامل پیشنهاد عملی باشند.
- برای تایید دستورات از عبارت‌های «حتماً» یا «با کمال میل» استفاده شود.

## خط مشی ترجمه انگلیسی
- در صورت نیاز به نمایش عبارات انگلیسی (مانند اسم هتل یا رستوران)، از فونت لاتین سازگار در کنار متن فارسی استفاده شود.

> این راهنما باید در کنار تست‌های کاربری بازنگری شود تا لحن مطابق انتظارات کاربران باقی بماند.
