# وایرفریم‌های متنی SafarYar

> وایرفریم‌ها به‌صورت توصیفی/ASCII ارائه شده‌اند تا تیم طراحی بتواند نسخه‌های وفادار در Figma بسازد. همه صفحات راست‌به‌چپ هستند.

## 1. Splash Screen
```
+-------------------------------------+
|        گرادیان Sunset Hero         |
|      لوگو سفر یار (سفید)           |
|    متن: «کجا دلت می‌خواد بری؟»     |
+-------------------------------------+
```

## 2. Onboarding Intro
- اسلایدر ۳ مرحله‌ای با تصویر تمام عرض.
- CTA: «شروع کن».

## 3. Interest Questionnaire
- کارت‌های انتخاب چندگانه (جنگل، کویر، تاریخی).
- نوار پیشرفت بالا.

## 4. Mood Questionnaire
- دکمه‌های انتخاب حالت: خلوت، شلوغ.
- توضیح کوتاه زیر هر گزینه.

## 5. Budget Input
- اسلایدر بودجه + فیلد عددی.
- پیام راهنما.

## 6. Location Permission
- تصویر نقشه، متن قانع‌کننده، دو دکمه «اجازه بده» و «بعداً».

## 7. Signup
- فیلد شماره موبایل، دکمه ادامه.
- لینک ورود.

## 8. Login
- فیلد شماره/رمز.
- گزینه ورود با Google/Apple.

## 9. Forgot Password
- فیلد ایمیل/شماره.
- دکمه «ارسال لینک بازیابی».

## 10. Home / Discovery
```
Header: سلام مهسا! (آیکون پروفایل)
Search Bar + آیکون میکروفن
Carousel پیشنهادها
Section مقصدهای محبوب
Section رویدادهای پیش‌رو
Bottom Tab: خانه، نقشه، سفر من، کیف پول، بیشتر
```

## 11. Iran Map View
- نقشه Mapbox، پین شهرها.
- Bottom Sheet با کارت‌های مقصد.

## 12. City Details
- تصویر Hero، آب‌وهوا، دکمه «شروع سفر».
- تب‌ها: دیدنی‌ها، اقامت، غذا.

## 13. Attractions List
- لیست کارت با تصویر، زمان بازدید، فاصله.
- فیلتر دسته‌بندی.

## 14. Attraction Details
- گالری تصویر، توضیح، ساعات بازدید.
- دکمه افزودن به برنامه سفر.

## 15. Weather Modal
- کارت آب‌وهوا با آیکون Lucide.
- پیش‌بینی ۵ روزه.

## 16. Trip Start Prompt
- Modal: «می‌خوای بری اصفهان؟» + CTA شروع برنامه.

## 17. Date Picker
- تقویم جلالی با انتخاب بازه.

## 18. Stay Type
- کارت انتخاب (بومگردی، هتل، آپارتمان).
- توضیح بودجه پیشنهادی.

## 19. Stay Results
```
Header: نتایج اقامت
Filter Chips (قیمت، امتیاز، خانوادگی)
Card: تصویر، قیمت، امتیاز، دکمه رزرو
```

## 20. Stay Details + Booking
- اسلایدر عکس، امکانات، نظرات.
- فرم رزرو با تعداد نفرات.

## 21. Transport Mode
- کارت‌های بزرگ: قطار، هواپیما، ماشین.
- نمایش ETA و هزینه.

## 22. Transport Results
- لیست بلیت‌ها با زمان، قیمت، لوگو شرکت.
- CTA رزرو.

## 23. Ticket Details / Seat Selection
- طرح صندلی (Grid).
- خلاصه پرداخت.

## 24. Car Rental
- کارت خودرو، ظرفیت، قیمت روزانه.
- گزینه افزودن راننده.

## 25. Budget Planner
- نمودار دونات تقسیم هزینه.
- فیلد افزودن هزینه جدید.

## 26. Generated Itinerary
- Timeline روزانه.
- امکان Drag & Drop فعالیت‌ها.

## 27. Group Wallet
- مانده کیف پول، کارت تراکنش‌ها.
- دکمه «تقسیم دونگ».

## 28. Split Costs (دونگ)
- فرم تقسیم هزینه بین اعضا.
- نمایش سهم هر نفر.

## 29. Nearby Restaurants
- کارت افقی با تصویر، فاصله، امتیاز.
- دکمه «نمایش روی نقشه».

## 30. Restaurant Details / Order
- منو به صورت لیست کشویی.
- گزینه رزرو میز یا سفارش ارسال.

## 31. Voice Assistant Overlay
- waveform انیمیشنی، متن پاسخ.
- دکمه دستورات پیشنهادی.

## 32. Achievements Badges
- Grid نشان‌ها با درصد پیشرفت.

## حالات ویژه
- **Offline Mode:** بنر اطلاع‌رسانی در بالای صفحه.
- **Error State:** تصویر Empty State + دکمه تلاش مجدد.

> نسخه‌ی تصویری این وایرفریم‌ها باید در Figma ساخته و لینک آن به مخزن اضافه شود.
