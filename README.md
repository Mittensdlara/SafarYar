# سفر یار (SafarYar)

برنامه‌ی جامع گردشگری فارسی که با تمرکز بر شخصی‌سازی، بودجه‌بندی هوشمند و تجربه کاربری صمیمی طراحی شده است. این مخزن شامل اسناد محصول، معماری و راهنمای نگارشی برای پیاده‌سازی اپلیکیشن کراس-پلتفرم (React Native + Next.js 14) است.

## 🎯 اهداف کلیدی
- پیشنهاد مقصد و برنامه سفر بر پایه‌ی هوش مصنوعی و داده‌های شخصی کاربران
- تسهیل رزرو اقامت، حمل‌ونقل و رستوران در یک تجربه یکپارچه
- پشتیبانی از سفرهای انفرادی، خانوادگی و گروهی با کیف پول اشتراکی
- ارائه‌ی رابط کاربری راست‌به‌چپ با نگارش فارسی الهام‌بخش و محاوره‌ای

## ⚙️ پشته فنی پیشنهادی
- **موبایل:** React Native + Expo Router، Zustand، React Query
- **وب/پنل:** Next.js 14 App Router، shadcn/ui، TailwindCSS، Framer Motion
- **بک‌اند:** NestJS (REST + WebSocket) روی Node.js 20، PostgreSQL + Prisma ORM، Redis برای کش، OpenAI Assistants برای پیشنهادها
- **احراز هویت:** NextAuth.js با پشتیبانی OAuth و رمز یکبارمصرف پیامکی
- **زیرساخت:** Docker Compose، CI/CD با GitHub Actions، میزبانی Railway/Render، شیفت آلارم Sentry + Logtail
- **یکپارچه‌سازی API:** Mapbox، OpenWeatherMap، سرویس‌های موک برای هتل و رستوران، درگاه پرداخت زرین‌پال (Sandbox)

## 🗺️ اولویت‌های توسعه (Roadmap)
1. **فاز اکتشاف (Discovery)**
   - اعتبارسنجی نیازهای چهار پرسونای اصلی
   - تعریف KPIهای تجربه کاربری (زمان تا رزرو، نرخ تکمیل بودجه‌بندی و ...)
2. **فاز طراحی**
   - طراحی جریان‌ها و وایرفریم‌های دقیق (موجود در `docs/`)
   - طراحی سیستم طراحی با استفاده از توکن‌های تعریف‌شده
3. **فاز پیاده‌سازی**
   - ایجاد مونو ریپو با Turborepo (پروژه Next.js + React Native + NestJS)
   - راه‌اندازی پایگاه داده و اسکریپت‌های Seed براساس مقاصد ایرانی
   - پیاده‌سازی موتور پیشنهاددهی (قوانین اولیه + مدل AI)
4. **فاز تحویل و بهینه‌سازی**
   - تست کاربری (قابلیت استفاده و محلی‌سازی)
   - بهینه‌سازی عملکرد (Lighthouse، پروفایلینگ React Native)
   - استقرار نسخه بتا و جمع‌آوری بازخورد
